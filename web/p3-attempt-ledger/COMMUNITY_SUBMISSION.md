# Community Contribution submission

- **Kind:** build
- **Title:** VEC P3 Attempt Ledger — offline tracker for the two scored submissions per board
- **Public link:** https://github.com/random-guy-05/vec-p3-attempt-ledger
- **What it is, and who it helps:** A self-contained offline browser tool for teams preparing P3. It tracks each team's manually recorded scored submissions against the two-per-board phase-wide limit while listing unlimited format checks separately. Data stays in browser storage, with JSON backup and restore. It is explicitly not connected to the Challenge portal; the official portal remains authoritative.
- **How someone else runs it:** Open `index.html` in a modern browser, or serve the folder locally with `python3 -m http.server 8000` for reliable browser storage. Add board names and record each official portal action.
