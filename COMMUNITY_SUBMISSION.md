# Community Contribution Award submission

**Kind:** organize  
**Title:** VEC Peer Workshop Kit — a facilitator-ready workshop for a reproducible first workflow  
**Public link:** https://github.com/random-guy-05/vec-workshop-kit

This is a complete 75-minute workshop for first-time Virtual Embryo Challenge participants, students, and collaborators. It gives facilitators a run-of-show, accessible browser-based slides, participant exercises, an answer key, and a 60-minute adaptation. Learners practice finding resources, interpreting what validators and local scores establish, checking external-data provenance against current rules, and recording enough detail to reproduce a run. It requires no programming, challenge data, account, or software installation. Every scenario is fictional, and the kit explicitly avoids collecting private data or asking participants to reveal team strategies.

To run it, use the preparation checklist and time blocks in `FACILITATOR_GUIDE.md`; share `PARTICIPANT_WORKSHEET.md` and open `slides.html` in any modern browser. Before each session, check the linked official Challenge pages because rules and dates can change. This kit is an independent community resource, not an official event or endorsement.
