# VEC Peer Workshop Kit

A facilitator-ready, low-barrier workshop for helping new Virtual Embryo Challenge participants find the right resources, check what a tool actually guarantees, and plan a reproducible first workflow. The session uses public challenge pages and the participant worksheet; no challenge data, account, model, cloud service, or software installation is required.

## Contents

- `FACILITATOR_GUIDE.md` — a 75-minute run-of-show, preparation checklist, prompts, and a 60-minute adaptation.
- `PARTICIPANT_WORKSHEET.md` — printable or screen-shareable group exercises.
- `slides.html` — a standalone, screen-reader-friendly slide deck. Open it in a browser and use the table of contents to jump between sections.
- `LICENSE` — MIT.

## Workshop at a glance

Participants practice four transferable skills: locating a relevant resource; distinguishing a format check from scientific evaluation; screening external data against current rules and source terms; and identifying the records needed to reproduce a run. They leave with a small, written next-step plan rather than a promised model score.

The guide is designed for 4–20 learners, one facilitator, and a 75-minute session. It can run in person or remotely. A 60-minute version is included. No one needs to show private code, upload a file, or disclose a team's approach.

## Run it

1. Read the facilitator guide and open the official [Challenge overview](https://virtualembryo.ai/challenge), [rules](https://virtualembryo.ai/challenge/rules), and [community resources](https://virtualembryo.ai/challenge/resources).
2. Share the worksheet and slides. Ask participants to work in pairs; all scenarios are fictional.
3. Facilitate the timed activities. When a rule or metric detail matters, point to the current official page rather than relying on a remembered answer.
4. Close with each participant choosing one low-risk next step and one check they will do before submitting.

The material is intentionally tool-neutral. It helps entrants navigate and reason about the ecosystem; it does not replace official documentation, provide competition advice, or claim that any third-party resource is endorsed.

## Update notes

The links above point to the live Challenge pages. Review the facilitator guide before each event because dates, board contracts, and rules may change. Send corrections as a public issue or pull request.
