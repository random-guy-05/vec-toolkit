# VEC P3 Survival Guide

A four-page illustrated guide to the Virtual Embryo Challenge final test phase beginning **20 October 2026**.

## Deliverables

- `VEC_P3_SURVIVAL_GUIDE.pdf` - complete four-page guide
- `assets/svg/` - editable source pages
- `assets/png/` - high-resolution shareable pages
- `assets/pdf/` - individual PDF pages
- `docs/SOURCES.md` - dated official source contract
- `docs/ALT_TEXT.md` - accessibility descriptions

The guide covers the information boundary at P3, hidden test targets, two-official-submissions-per-board rule, unlimited format checks, non-withdrawal, and a final artifact workflow. It is a community reference, not official Challenge guidance.
