1 · Four useful outcomes

  • Know the question your chosen task asks.
  • Find a resource that matches your current problem.
  • Say what a tool result does and does not establish.
  • Write one next action and one check before submission.

2 · Start with the task definition

Use the current official task page to identify the inputs, prediction target, permitted information, and output expectations. Do not infer those details from a repository name or an old tutorial.

Open the current task descriptions.

3 · Match a resource to a need

Search by workflow or task, then open the original. Check the author's prerequisites, supported use, run steps, license, and limitations. A listing is a pointer, not an endorsement.

Official resource list · Searchable navigator.

4 · Three different claims

  • Format check: specified file conditions passed.
  • Local comparison: methods were compared under one chosen split and protocol.
  • Official evaluation: the challenge server and current rules determine the competition result.

Do not turn one claim into another. A passing validator does not establish biological correctness, data eligibility, or hidden-target performance.

5 · Public does not automatically mean eligible

Record the exact source and release, inspect reuse terms, explain task relevance, check the current Challenge rules, and preserve provenance. Pause when a rule or license is unclear.

Read the current Challenge rules.

6 · Make a run traceable

  • Code revision and working-tree state
  • Environment, versions, and configuration
  • Input provenance and permitted identifiers
  • Command, random seed, and output path
  • Evidence tying the evaluated file to the final file

Logs and hashes support review; no single record proves full rule compliance by itself.

7 · Choose one next step

Write an action small enough to do next, the official page or resource it depends on, and one check you will make before relying on the result.

Use the participant worksheet for the exercises and notes. Confirm time-sensitive details on the official pages before each workshop.
